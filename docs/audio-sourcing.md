# Audio sourcing notes

The built-in library is presented as original demo audio inspired by social formats, not as a collection of copyrighted viral-song excerpts. For later production asset replacement, Mixkit states that its free sound effects can be used in commercial and personal projects without attribution, while also advising users to read its license and terms.[1] SoundHelix explicitly allows its MP3 examples to be used in any way provided that SoundHelix and the respective artist are credited.[2] Pixabay provides music and sound-effect discovery pages, but each downloaded asset should still be checked against the applicable item license before bundling.[3]

The current prototype uses remote SoundHelix example URLs as playable demo sources and should show attribution in production-facing legal copy if those sources remain bundled. A safer production hardening step is to replace the demo URLs with downloaded, reviewed assets from a source whose license allows redistribution inside an app, or with original generated clips owned by the project.
